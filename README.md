# 🏥 Natural Language Interface for Healthcare Infrastructure

## 📌 Overview

A simple healthcare chatbot developed using **Python** and **Streamlit**. The chatbot provides quick responses to healthcare-related queries such as doctor availability, ambulance services, bed status, and appointments using keyword matching.



## 🚀 Features

* Healthcare chatbot interface
* Doctor availability information
* Ambulance service details
* Bed availability status
* Appointment information
* Chat history dashboard
* JSON-based dataset


## 🛠 Technologies Used

* Python
* Streamlit
* JSON
* Keyword Matching
